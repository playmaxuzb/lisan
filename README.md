# لِسان · Lisan · Лисан

منصة لتعلّم اللغات من الصفر حتى مستوى C2، بأربعة مسارات:

| المسار | لغة الشرح | اللغة المستهدفة |
|---|---|---|
| عربي ← روسي | العربية | الروسية |
| عربي ← إنجليزي | العربية | الإنجليزية |
| Русский → английский | الروسية | الإنجليزية |
| Русский → арабский | الروسية | العربية |

**كل مستوى (A1–C2) يحتوي على:**
- أكثر من 200 كلمة مع صورة ونطق ومعنى
- أكثر من 100 جملة يومية
- دروس قواعد مع أسئلة للتحقق من الفهم
- 4 نصوص قراءة، وكل كلمة فيها قابلة للضغط لسماعها ومعرفة معناها
- 4 محادثات بصوتين
- تمارين كتابة: تتبّع الحروف، إملاء، نسخ الجمل
- امتحان من 20 سؤالاً، والنجاح بـ 80٪ يفتح المستوى التالي

## التشغيل

الموقع ملف واحد هو `index.html` مع مجلد `audio/` للتسجيلات الصوتية، ويعمل مباشرة على GitHub Pages.

للتجربة على جهازك:

```
python3 -m http.server
```

ثم افتح `http://localhost:8000`.

## بنية المشروع

- `index.html`: الموقع كاملاً (الواجهة والمحتوى والقاموس)
- `audio/`: التسجيلات الصوتية لكل لغة ومستوى
- `src/curriculum/`: المنهج الأساسي (روسي، إنجليزي، عربي مشكّل)
- `src/`: الكود والقواميس وسكربت البناء `build.sh`
- `src/tools/`: أدوات توليد الصوت والتحقق من النبرة الروسية
