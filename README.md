# لِسان · Lisan

منصة مجانية لتعلّم ست لغات من الصفر حتى مستوى C2:
العربية · الروسية · الإنجليزية · الأوزبكية · الإسبانية · الصينية.

كل لغة من الست تكون لغةً أمّاً ولغةً للتعلّم في الوقت نفسه، فصاحب كل لغة يتعلّم الخمس الأخرى، والمجموع **30 دورة**.
بعد اختيار اللغة الأم تظهر المنصة كلها بهذه اللغة، وكل الشروحات والمعاني داخل الدورات تكون بها.

## تجربة المستخدم

1. **اختيار اللغة الأم**: أول شاشة، وتُعرض بلغة المتصفح (أو الإنجليزية إن لم تكن من الست).
2. **تسجيل الدخول**: بالبريد الإلكتروني أو رقم الهاتف، أو بزر Google، أو الدخول كضيف.
3. **اسم المستخدم والصورة**: اسم مستخدم، وصورة رمزية جاهزة أو صورة من الجهاز.
4. **الواجهة الرئيسية**: الدورات الخمس المتاحة للغتك مع التقدّم في كل منها.
5. **الملف الشخصي**: صورة الغلاف، الصورة الشخصية، اسم المستخدم، تغيير اللغة الأم، والإحصاءات.

## محتوى كل مستوى (A1–C2)

- الحروف أو جدول البنيين (في A1)
- أكثر من 200 كلمة مع صورة ونطق ومعنى
- أكثر من 100 جملة
- دروس قواعد مع أسئلة للتحقق من الفهم
- نصوص قراءة، وكل كلمة فيها قابلة للضغط لسماعها ومعرفة معناها
- محادثات بصوتين مع وضع لعب الأدوار
- كتابة: تتبّع الحروف بعدة خطوط، إملاء، نسخ الجمل
- امتحان من 20 سؤالاً، والنجاح بـ 80٪ يفتح المستوى التالي

## تفعيل الدخول الحقيقي (Firebase)

بدون إعداد، تُحفظ الحسابات والتقدّم على جهاز المستخدم.
لتفعيل التحقق بالبريد والهاتف وGoogle ومزامنة التقدّم بين الأجهزة:

1. أنشئ مشروعاً على [Firebase](https://console.firebase.google.com) وأضف تطبيق ويب.
2. فعّل في Authentication طرق الدخول: Email link، وPhone، وGoogle، وأضف نطاق الموقع إلى Authorized domains.
3. فعّل Firestore Database.
4. انسخ `firebase-config.example.json` إلى `firebase-config.json` في جذر الموقع وضع فيه مفاتيح مشروعك.

لا حاجة لإعادة بناء الموقع: يقرأ الموقع الملف عند التشغيل.

## بنية المستودع

- `index.html` و`assets/`: الموقع المبني (React + Tailwind)
- `data/`: بيانات الدورات (30 دورة)
- `audio/`: التسجيلات الصوتية لكل لغة ومستوى
- `avatars/`: الصور الرمزية الجاهزة
- `app/`: الشيفرة المصدرية للواجهة (Vite + React + TypeScript + Tailwind)
- `content/`: المنهج ومولّد البيانات (`gen3.js`، `pinyin.py`)

## البناء

```
cd app && npm install && npx vite build
cd ../content && node gen3.js ../app/public/data && python3 pinyin.py ../app/public/data/M_zh.json
```

للتجربة محلياً: `python3 -m http.server` في جذر المستودع ثم افتح `http://localhost:8000`.
